# 错误码 Reference

> 来源：`backend/app/exceptions/error_codes.py`。响应统一为 `{code, message, data}`。

## 通用

| 错误码 | HTTP | 含义 |
| --- | ---: | --- |
| 0 | 200 | 成功 |
| 40000 | 400 | 参数错误（含校验失败） |
| 40100 | 401 | 未认证或 Token 无效 |
| 40300 | 403 | 无权限 |
| 40400 | 404 | 资源不存在 |
| 40900 | 409 | 资源冲突 |
| 50000 | 500 | 服务器内部错误 |

## 参数与时间

| 错误码 | HTTP | 含义 |
| --- | ---: | --- |
| 40001 | 400 | 采集时间非法 |
| 40002 | 400 | 任务操作类型非法 |

## 认证与权限

| 错误码 | HTTP | 含义 |
| --- | ---: | --- |
| 40101 | 401 | 用户名或密码错误 |
| 40102 | 401 | 账号已禁用 |
| 40103 | 401 | Agent 凭证无效 |
| 40301 | 403 | 服务不允许受控操作 |

## 资源不存在

| 错误码 | HTTP | 含义 |
| --- | ---: | --- |
| 40401 | 404 | 用户不存在 |
| 40402 | 404 | 角色不存在 |
| 40403 | 404 | 服务器不存在 |
| 40404 | 404 | 告警规则不存在 |
| 40405 | 404 | 告警事件不存在 |
| 40406 | 404 | 任务不存在 |
| 40407 | 404 | 任务执行记录不存在 |
| 40408 | 404 | 服务器服务不存在 |

## 冲突

| 错误码 | HTTP | 含义 |
| --- | ---: | --- |
| 40901 | 409 | 用户名已存在 |
| 40902 | 409 | 邮箱已存在 |
| 40903 | 409 | 服务器编码已存在 |
| 40904 | 409 | IP 与端口已被占用 |
| 40905 | 409 | 规则名称已存在 |
